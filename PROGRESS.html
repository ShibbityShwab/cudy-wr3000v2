The wall (interrupt + dialogue): every host-side move the verified maps name has been performed to the vendor's own values. The last hop — the Wi-Fi chip's ctrl-rb delivering its latched interrupt to the GIC — is inside the device, unreachable from the host by every mechanism this bench contains (phase48/host-side-closed.md). Only two instruments could open it and both are confirmed unavailable: JTAG (no hardware) and the vendor source (Cudy + Jeton requests both silent).
What changed in this audit (2026-10-11): three scores were wrong and are corrected — PCIe host driver 35→25% (the LTSSM/mode/IATU writes are all commented out), NAND/FMC driver 30→55% (3,422 lines, erase measured working), Ethernet driver 5→0% (no file exists). Headline: overall 50.5→51.0%.

Left, in order: (1) un-strand the board — bound the NAND erase-verify loop to a sample so boot can't hang; (2) finish NAND (erase race + UBI/JFFS2 attach); (3) write the Ethernet/switch driver (0%); (4) fill the stub drivers (clk mux, pinctrl set_mux, PCIe writes); (5) the Wi-Fi wall + data path.
